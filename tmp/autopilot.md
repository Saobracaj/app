# Добработки автопилота
## Требования
1. Автопилот можно вызвать в любой момент командой autopilot в терминале.
2. В него можно добавить/удалить проекты (дирректории), которые он контролирует.
3. Можно приостановить/возобновить действие любого из проектов
4. Просмотр статуса работы и последних логов
5. Установка приоритетов для проектов
6. В поставку также включена утилита для работы с asana, которая работает с теми же конфигами
7. Конфиги и логи автопилота хранятся в дирректориях autopilot каждого проекта
8. Нужна возможность управлять автопилотом через telegram бота (в том числе через inline кнопки) -- приостановка конкретных проектов, возобновление, просмотр статуса и логов, установка приоритетов. 


## Инициализация проекта в автопилоте
При добавлении проекта автопилот может исопльзовать claude code, модель sonnet, medium effort.

Нужно создать в соответствующем проекте дирректорию autopilot, в которую поместить нужные файлы (env.yaml, помпт)

Также нужно добавить в память проекта информацию об автопилоте (чтобы можно было спрашивать у claude code про автопилот из любого контролируемого проекта).
