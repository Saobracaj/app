# Konspekt style guide

Цель конспекта — чтобы пользователь **правильно отвечал на вопросы экзамена**,
а не изучал закон. Это шпаргалка с логикой, не учебник.

## Главные принципы

1. **Ответ важнее теории.** Не пересказывай закон и определения — дай
   правило, по которому выбирается правильный вариант. Если во всех
   вопросах про регулирование движения правильный ответ — *униформисани
   полицијски службеници*, так и напиши: «видишь этот вариант — выбирай
   его, это правильный ответ всегда».
2. **Логические цепочки, а не списки фактов.** Каждый раздел должен
   оставлять в голове простой алгоритм: «спрашивают X → смотри на Y →
   выбирай Z». Формулируй правила выбора явно.
3. **Ловушки.** Если в вопросах есть типовые неправильные варианты-приманки
   (похожие термины, «почти правильные» формулировки), назови их и объясни,
   как их отличать. Пары путаемых терминов (*претицање/обилажење/
   мимоилажење*, *коловоз/пут*, *мопед/мотоцикл*) — главный источник ошибок.
4. **Минимальность.** Всё, что не помогает ответить ни на один вопрос
   категории, — выкинуть. Числа, даты и списки заучиваются только если
   про них спрашивают.

## Язык и терминология

- Язык конспекта — русский. Сербские слова — *курсивом*.
- Ключевые экзаменационные термины (*саобраћај*, *претицање*,
  *мимоилажење*, *коловоз*…) **не переводить** в тексте — пользователь
  должен узнавать их в сербском вопросе. При первом упоминании дать
  перевод в скобках: «*претицање* (обгон)».
- Цитаты из вариантов ответов приводить по-сербски дословно (курсивом) —
  пользователь должен узнать точную формулировку в тесте.
- В словарь (`dictionary`) выносить именно эти ключевые термины: слово |
  перевод, markdown-таблицей. Не тащить туда случайную лексику — только
  слова, без знания которых не понять вопрос или варианты ответов.

## Структура

- Разделы — по смысловым темам (группам похожих вопросов), не по номерам
  подкатегорий. 5–15 разделов на категорию; раздел — от пары абзацев до
  страницы.
- В каждом разделе: правило/цепочка → детали и ловушки → 2–4 ссылки на
  типовые вопросы-примеры вида `[№7921](question?id=7921)` прямо в тексте.
- `questionIds` раздела — полный список вопросов, которым раздел помогает;
  валидатор требует, чтобы объединение по разделам покрывало все вопросы
  категории.
- Иллюстрация/анимация — там, где текстом объяснять дольше, чем показать
  (различие манёвров, части дороги, траектории). В `description.ru` пиши
  ТЗ для художника: что изображено, что подписано, что анимируется.
- Таблицы — для контрастных пар («термин → как отличить»), это лучший
  формат для определений.

## Тон

Разговорный, прямой, без канцелярита. «Запомни», «не путай», «если в
вариантах есть … — это ответ». Можно мнемоники и опоры на русские
однокоренные слова (*мимоилажење* — «идут мимо друг друга»).
