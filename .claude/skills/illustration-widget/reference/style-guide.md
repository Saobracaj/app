# Как рисовать

Правила ниже — не вкусовщина: каждое из них родилось из конкретной поломки
(подпись уехала за край, чёрный текст на тёмной теме, анимация не
останавливается и её невозможно прочитать).

## 1. Холст

Рисуй в **фиксированной системе координат** и масштабируй целиком:

```dart
FittedBox(
  fit: BoxFit.contain,
  child: SizedBox(
    width: 400,
    height: 260,
    child: CustomPaint(painter: _Painter(colorScheme, labels)),
  ),
)
```

Почему так: координаты в `paint()` становятся обычными числами (`Offset(200,
120)`), ничего не пересчитывается под ширину экрана, а на планшете и на
телефоне картинка выглядит одинаково.

- Пропорции: ширина 320–400, высота — по содержанию. Схема выше 1.5×ширины
  на телефоне читается плохо; вместо длинной колонки лучше две компактных.
- Никакого `MediaQuery.of(context).size` внутри иллюстрации (так сделано в
  старых сценах `obilazenje1.dart` / `propustanje.dart` — на широком экране
  они разъезжаются). Нужны реальные размеры родителя — `LayoutBuilder`.
- Сцена «вид сверху на дорогу» — исключение: она растягивается на всю
  ширину (`Stack` + `Positioned.fill(child: RoadView())`) при фиксированной
  высоте 180–220.

## 2. Цвета

Смысловые цвета — **из темы**, чтобы иллюстрация читалась и в тёмном режиме:

```dart
final scheme = Theme.of(context).colorScheme;
```

| Роль в схеме | Цвет |
| --- | --- |
| Фон блока/карточки | `surfaceContainerHighest` |
| Нейтральный блок-пояснение | `secondaryContainer` / `onSecondaryContainer` |
| «Хорошо», разрешено | `tertiaryContainer` / `onTertiaryContainer` |
| «Плохо», запрещено, ловушка | `errorContainer` / `onErrorContainer` |
| Главный акцент, итог | `primaryContainer` / `onPrimaryContainer` |
| Линии, рамки, стрелки | `outline` |
| Текст на фоне схемы | `onSurface` |
| Асфальт | `surfaceContainerHighest` затемнённый или `Colors.grey.shade800` — как в `road.dart`, ради единого вида сцен |

Литеральные цвета допустимы **только там, где цвет и есть содержание**:
разметка (белая/жёлтая), сигналы светофора, синий/красно-синий/жёлтый
маячок, красный треугольник, цвета машин в сцене (синяя/зелёная — чтобы
различать участников). Всё остальное — из схемы.

Проверка: отрендерь обе темы (`THEMES=light,dark`) и посмотри. Чёрный текст
на тёмной теме — самая частая ошибка.

Смысл не должен держаться **только** на цвете: рядом с красным блоком должно
быть слово «забрањено» или крестик.

## 3. Текст и локализация

- Шрифт: в `TextStyle` для `TextPainter` всегда указывай
  `fontFamily: kAppFontFamily` (`lib/theme/app_theme.dart`). Без этого текст
  рисуется системным шрифтом, а в тестовом рендере — квадратами.
- Кегль: не меньше 11 при холсте шириной 400 (после `FittedBox` это ≈ 10 pt
  на телефоне). Длинную подпись лучше перенести (`\n`), чем ужать.
- **Сербские термины не переводятся** — ни на русский, ни на английский:
  `одстојање`, `путничко возило`, `забрањено`. Они прямо в коде.
- Русские пояснения («да», «нет», «путь реакции») — переводимые:
  ключ в `assets/translations/{ru,sr,en}.json`, доступ через
  `LocaleKeys.…` и `context.tr(...)`, затем `./codegen.sh`.
- Painter кэширует подписи, поэтому **читай их в `build()` через
  `BuildContext`** и передавай в painter объектом с `==`/`hashCode` — иначе
  при смене языка картинка останется на старом (см. `_TreeLabels` в
  `decision_tree_widget.dart`).
- `shouldRepaint` должен сравнивать и `colorScheme`, и подписи.

## 4. Анимация

- `AnimationController` + `SingleTickerProviderStateMixin`, обязательный
  `dispose()`. Это единственный разрешённый в приложении `StatefulWidget`
  без Bloc (см. `app/CLAUDE.md`).
- Цикл 4–8 секунд, `..repeat()`. Быстрее — не успеть прочитать, длиннее —
  пользователь не дождётся второго круга.
- В конце цикла **пауза**: без неё сцена выглядит как дёрганая петля.

  ```dart
  _y = TweenSequence([
    TweenSequenceItem(tween: Tween(begin: 0.0, end: -0.3), weight: 20),
    TweenSequenceItem(tween: ConstantTween(-0.3), weight: 30),
    TweenSequenceItem(tween: Tween(begin: -0.3, end: 0.0), weight: 20),
    TweenSequenceItem(tween: ConstantTween(0.0), weight: 30),
  ]).animate(CurvedAnimation(parent: _c, curve: Curves.easeInOut));
  ```

- Каждая фаза подписана текстом в углу сцены (как `Positioned(top: 8, left:
  8, child: Text('Мимолажење'))`). Если фаз несколько — подпись меняется
  вместе с фазой: пользователь должен понимать, что именно он смотрит.
- Неподвижное ТС отличается от движущегося не только положением: включённая
  аварийка, отсутствие стрелки движения.
- Никаких `Timer.periodic` в новых виджетах для анимации (в `auto.dart` он
  исторический) — только контроллер, иначе кадр не поймать в рендере.
- Анимация должна быть понятна и по **стоп-кадру**: пользователь может
  открыть текст и промотать мимо. Ключевая фаза — читаемая картинка сама по
  себе.

## 5. Структура кода

```
lib/test/animations/<slug_snake>.dart
  class <ИмяВиджета> extends StatelessWidget   // или StatefulWidget для анимации
  class _<Имя>Labels                            // если есть переводимые подписи
  class _<Имя>Painter extends CustomPainter     // приватный
```

- Один слаг — один файл. Общие куски выносить в отдельный публичный виджет,
  а не копировать.
- Вспомогательные рисовалки (`_drawBox`, `_drawArrow`, `_drawText`) уже
  написаны в `decision_tree_widget.dart` — при третьем копировании выноси их
  в общий `painters.dart`, а не плоди четвёртую копию.
- Комментарии в коде — по-русски, как в остальном каталоге, и объясняют
  *почему* (почему такая геометрия/пауза), а не *что*.
